# Health360 – Healthcare Analytics

## Project Overview
Health360 is a healthcare analytics project that uses Tableau to explore patient data and Flask to provide a web interface for presenting the project.

## Objectives
- Analyze healthcare data and patient health indicators.
- Visualize trends and patterns using Tableau dashboards.
- Present healthcare insights through a simple web interface.
- Practice data visualization and web development skills.

## Technologies Used
- **Tableau Desktop:** Dashboard and data visualization
- **Python:** Application logic
- **Flask:** Web framework
- **HTML, CSS, JavaScript:** Website interface
- **CSV:** Patient dataset

## Project Files
- `app.py` – Flask application
- `templates/` – HTML templates used by Flask
- `static/` – Website styles, scripts, images, and other assets
- `Health360 Project - FINAL.twb` – Tableau workbook
- `smart_healthcare_dataset.csv` – Healthcare dataset

## Tableau Dashboard
The Tableau workbook is included in this repository. To view the interactive dashboard online, add your published Tableau dashboard URL here.

## How to Run the Website

1. Install Python.
2. Install Flask:

   ```bash
   pip install flask
   ```

3. Open a terminal in the project folder.
4. Run the application:

   ```bash
   python app.py
   ```

5. Open the local URL displayed in the terminal, usually `http://127.0.0.1:5000/` or the port configured in `app.py`.

## Dataset and Privacy
This project is intended for educational purposes. Verify that the dataset contains no real patient-identifying information before sharing it publicly.
